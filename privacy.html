Privacy policy

mydrive requests only the Google Drive drive.file scope, so it can see and change only files that mydrive itself created. It cannot read any other file in the Drive.

The files it uploads are the owner's own server backups, encrypted before they leave the owner's hardware.

mydrive collects no personal information, sends no data to any party other than Google Drive, uses no analytics or cookies, and shares nothing with anyone.

The OAuth token is stored only on the owner's own server. Access can be revoked at any time at myaccount.google.com/permissions.
